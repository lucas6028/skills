# 中文 AI 痕跡清單與替代策略

三個層次:詞彙、用字(簡繁/兩岸)、句式篇章。詞彙層 grep 得到,句式層要用讀的。

## 一、詞彙黑名單

原則:替代策略幾乎都不是「換同義詞」,而是改寫句子讓那個位置不需要那類詞。
表中「改法」欄描述的是策略,不是固定替換詞。

### 開場濫調

| 黑名單 | 改法 |
|---|---|
| 隨著…的(快速/蓬勃/迅速)發展 | 直接從具體現象或問題切入,不鋪墊時代背景 |
| 在…的背景下 / 在…時代 | 同上;背景若真的必要,就用一句有具體事實的話寫出來 |
| 近年來,…已成為(熱門議題/研究焦點) | 說清楚是誰、哪些工作在關注,附引用;或直接刪 |
| 眾所周知 / 毋庸置疑 | 真的眾所周知就不用說;不是就給引用 |

### 強調與評價濫調

| 黑名單 | 改法 |
|---|---|
| 值得注意的是 / 值得一提的是 | 直接把那件事寫出來;它重要,內容自己會說話 |
| 不可忽視(的是) / 不容小覷 | 同上 |
| 扮演(著)…(的)角色 | 改成直述句:「X 決定了 Y」「X 是 Y 的前提」 |
| 至關重要 / 舉足輕重 / 關鍵作用 | 說明重要在哪:少了它會怎樣、有了它差多少 |
| 里程碑 / 開創性 / 突破性 | 讓事實與數字自己呈現份量 |

### 總結與過渡濫調

| 黑名單 | 改法 |
|---|---|
| 總而言之 / 總的來說 / 綜上所述 | 多數情況整段總結都該刪;真要收束(如結論章)就直接寫結論內容 |
| 首先…其次…(再者…)最後 | 用內容的邏輯關係銜接(因果、對比、遞進),不用序數框架 |
| 一方面…另一方面 | 偶用無妨,一篇超過一次就改:兩件事各自成句 |
| 與此同時 | 「同時」已足夠,且每段至多一個段首連接詞 |
| 接下來 / 下面(我們)將 | 學術寫作用「第 3 章說明…」這類指涉,或直接開始說 |

### 填充詞(刪掉或改直述)

| 黑名單 | 改法 |
|---|---|
| 深入(探討/分析/研究/了解) | 刪「深入」;深不深看內容 |
| 有效地 / 成功地 / 積極地 / 充分地 | 刪;或給出「多有效」的數字 |
| 全面(的/地) / 系統性(的/地) | 刪;或具體列出涵蓋範圍 |
| 一定程度上 / 某種程度上 | 若證據不足,說明哪裡不足;否則刪 |
| 在…方面 | 多數可刪:「在效能方面表現優異」→「效能較佳(數字)」 |
| 透過…的方式 | 「的方式」三字幾乎永遠可刪 |
| 進行 + 動名詞(進行分析/進行比較/進行訓練) | 直接用動詞:「分析」「比較」「訓練」 |
| 對…而言 / 就…來說(段首) | 常可刪或併入主句 |
| 不僅…更/還/也… | 偶用無妨,成為慣性就拆成兩個獨立句 |
| 進一步(地) | 一篇至多兩次;超過就描述實際動作 |

### 空泛強度詞

| 黑名單 | 改法 |
|---|---|
| 顯著提升 / 大幅改善 / 極大地 | 「顯著」只配統計檢定(給 p 值);其餘給數字與基準 |
| 廣泛應用於 | 列出兩三個具體應用並附引用,或刪 |
| 效能優異 / 表現出色 | 給數字、給比較對象 |

## 二、用字:台灣學術用語對照(禁用中國用語/支語)

繁體論文出現下列左欄詞是強烈的機器翻譯/AI 痕跡,在台灣的口試與審查場合也格外刺眼。
一律用右欄:

| 禁用 | 使用 |
|---|---|
| 信息 | 資訊 |
| 視頻 | 影片 |
| 軟件 / 硬件 | 軟體 / 硬體 |
| 網絡 | 網路 |
| 質量(指品質時) | 品質(物理學的質量不在此限) |
| 智能 | 智慧(如人工智慧) |
| 通過(表手段時) | 透過、藉由(「通過考試」不在此限) |
| 用戶 | 使用者 |
| 服務器 | 伺服器 |
| 內存 | 記憶體 |
| 代碼 | 程式碼 |
| 算法(單獨使用) | 演算法 |
| 缺省 | 預設 |
| 打印 | 列印 |
| 支持(指技術支援時) | 支援(「支持某論點」不在此限) |
| 反饋 | 回饋 |
| 概率 | 機率 |
| 變量 | 變數 |
| 程序(指程式時) | 程式(法律程序、實驗程序不在此限) |
| 對象(指 object 時) | 物件(研究對象不在此限) |
| 芯片 | 晶片 |
| 屏幕 | 螢幕 |
| 鼠標 / 光標 | 滑鼠 / 游標 |
| 硬盤 | 硬碟 |
| 默認 | 預設 |
| 激活 | 啟用、活化 |
| 兼容 | 相容 |
| 可視化 | 視覺化 |
| 數字化 | 數位化 |
| 移動端 / 移動設備 | 行動裝置 |
| 調用 | 呼叫 |
| 魯棒性 | 穩健性、強健性(robustness) |
| 高清 | 高畫質 |
| 渠道 | 管道 |
| 水平(指水準時) | 水準(水平方向不在此限) |
| 項目(指 project 時) | 專案、計畫(評估項目、檢核項目不在此限) |
| 落地(指導入時) | 實際應用、導入 |
| 優化 | 台灣學界兩者皆見,「最佳化」較正式;全篇擇一,不混用 |
| 數據 | 數值資料可用「數據」;泛指 data 用「資料」 |

注意不要誤殺台灣正規用語:統計的「交互作用」(interaction effect)、「顯著水準」
是台灣標準術語,保留。

另外全文不得出現任何簡體字(常見漏網:后、于、里、发、体、点、么、几、无)。

## 三、句式與篇章 tells

這一層 grep 不到,要用讀的。每一條都附判斷方法:

1. **等長句連發**:連續三句以上字數相近(差距 < 30%)。
   → 把其中的判斷句改短(十字內),或把兩句相關的併成一個長句。
2. **段首連接詞依賴**:一段裡兩句以上用「然而/此外/因此/同時」開頭。
   → 靠內容銜接:讓前句句尾的資訊成為後句句首的舊資訊,連接詞自然就不需要了。
3. **三項式慣性**:「A、B 與 C」型列舉反覆出現。真人列舉有時兩項、有時四項、
   有時一項帶說明。→ 全文至多留一處三項式。
4. **正文條列化**:該用散文的正文用了條列符號或編號清單。
   → 論文正文以段落為單位;條列保留給真正的枚舉場合(如貢獻列表,且依期刊慣例)。
5. **粗體濫用**:正文用粗體標重點是網路文章習慣,論文正文不用粗體強調。
6. **段尾總結句**:每段最後一句把該段重講一遍。→ 刪,段落停在最後一個實質論點。
7. **對稱段落**:每段長度、內部結構(主張+三個支持+小結)一模一樣。
   → 讓結構跟著內容走:有的段兩句,有的段八句。
8. **冒號引導的假分類**:「主要包含以下三個部分:」→ 直接寫,讀者看得出來有幾個部分。
9. **括號補充依賴**:頻繁用括號塞定義或補充。→ 重要就寫進正文,不重要就刪。
10. **問句修辭**:「那麼,如何解決這個問題呢?」論文不自問自答,直接陳述。
11. **引號依賴**:AI 特別愛用「」把概念框起來強調(判斷「有沒有做」而非
    「做得對不對」)。本 skill 的規範是:交付的論文正文完全不使用「」——
    需要強調的概念直接寫進句法裡(用語序、對比、下定義來突顯);專有名詞
    首次出現時附原文或定義即可,不加引號;真要引用他人文字,改為改寫
    (paraphrase)並附引用出處,學位論文極少需要逐字引文。

## 四、正當的學術套語(不要誤殺)

以下是 LLM 普及前的優秀論文就常見的學術語域,保留:

本研究、本文、所提方法、如圖 X 所示、如表 X 所列、據此、由此可知(適量)、
綜合上述實驗(在結論章)、假設檢定術語(顯著水準、信賴區間)、
領域固定譯名(卷積神經網路、注意力機制)。

判斷標準永遠是:2015 年的好論文會這樣寫嗎?會,就不是 AI 味。
